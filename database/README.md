# Base de données

Ce dossier accueille le schéma, les migrations et les éventuelles données de démonstration non sensibles.

Le stockage doit couvrir les mesures, événements IA, incidents, commandes et traces de supervision utiles. Définir les unités, horodatages, relations et durées de conservation avec les développeurs de l’API.

La technologie reste à choisir. La base sera accessible uniquement aux services internes autorisés ; aucun capteur ou navigateur ne s’y connecte directement.
