# IoT

Ce dossier accueille le firmware C++ de l’ESP8266 et la documentation de son câblage.

Périmètre : lecture cadencée des capteurs, affichage OLED, transmission sécurisée, réception des commandes LEDs/buzzer et retour d’état.

Documenter les composants retenus, broches, unités, fréquence de mesure, formats de messages et procédure de chargement du firmware. Les identifiants Wi-Fi et secrets des équipements ne doivent pas être versionnés.
