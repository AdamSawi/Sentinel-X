# Modèles IA

Ce dossier accueille l’analyse vidéo locale et l’analyse temporelle des capteurs.

- Vision : détecter une présence humaine suspecte depuis la webcam USB du serveur.
- Capteurs : préparer les données et détecter les anomalies de leur évolution.
- Évaluation : documenter les données utilisées, les limites, les erreurs et les temps de traitement.
- Intégration : transmettre à l’API des résultats horodatés et explicables.

Le choix des modèles reste ouvert. Documenter ici l’installation, les poids nécessaires et les commandes d’exécution lors de leur ajout. Ne pas versionner de vidéos de personnes ni de jeux de données sensibles.
